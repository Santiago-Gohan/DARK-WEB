# ImpactMind Enterprise

Prototipo web local para analizar necesidades empresariales, clasificar prioridades y estructurar propuestas de implementación.

## Ejecutar

Abre `index.html` directamente en un navegador moderno. No requiere instalación ni dependencias externas.

## Funciones de demostración

- Directorio local de empresas y búsqueda.
- Clasificación indicativa de necesidad de 0 a 100.
- Plan de proyecto con objetivo, integraciones a evaluar, fases e indicadores.
- Exportación de propuestas a JSON.
- Persistencia de los perfiles y proyectos en el almacenamiento local del navegador.

## Importante

Esta versión usa datos de muestra y reglas heurísticas. No está conectada a ERP, CRM, sensores ni otras fuentes en tiempo real; tampoco ejecuta cambios en sistemas empresariales. Para usarla con datos reales se necesitan integraciones, permisos, validación de seguridad y revisión humana del plan antes de implementarlo.
